## Metode Instalasi

1. **Clone Proyek**

```bash
git clone [https://git.nurulfikri.id/deptd/](https://git.nurulfikri.id/deptd/)[nama-repo].git
```

2. **Masuk ke folder proyek**

```bash
cd [nama-folder-proyek]
```

3. **Konfigurasi awal (Git identity dan Git Hooks)**

Linux/macOS/Git Bash:
```bash
./scripts/setup-hooks.sh
```

Windows PowerShell:
```ps
.\scripts\setup-hooks.ps1
```

4. **Install dependencies**

```bash
[pnpm/npm/yarn] install
```

5. **Start server (development)**

```bash
[pnpm/npm/yarn] run dev
```

Buka http://localhost:[port] di browser Anda untuk melihat halaman.

Proyek ini menggunakan [`[Nama Package/Alat]`]([URL Package]) agar dan memuat [`[Nama Aset]`]([URL Aset]), `[Jenis Aset]` besutan [`[Nama Pembuat/Perusahaan]`]([URL Pembuat]).
